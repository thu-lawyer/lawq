# 律问 · 法律检索问答

> 一个**检索透明、引用可溯源**的法律问答应用：提问后先在**内置现行法律库**（宪法 + 全国人大现行有效法律，26,196 条）中做 BM25 条级检索，再由大模型（智谱 glm-5.3-flash）**仅依据命中条文**生成回答——每条依据都标出相关度得分，可点开核对原文。
>
> **网页 + 微信小程序** 双端共用同一后端，部署于云服务器，绑定域名并启用 HTTPS 公网上线。
>
> 计算法学方法课程 · 打卡作业项目（示例）

## 快速开始

```bash
./start.sh
```

脚本自动：创建虚拟环境 → 安装依赖 → 构建法条库（首次，需课堂语料 `../宪法法律_条文.jsonl`）→ 启动服务 → 打开浏览器。默认 <http://127.0.0.1:8790>（换端口：`LAWQ_PORT=9000 ./start.sh`）。

> `.env` 中填入智谱开放平台的 `ZHIPU_API_KEY`（glm-5.3-flash）即开启智能问答；不配置也能用，此时回答退化为"直接返回检索到的法条原文"。

## 功能速览

| 功能 | 说明 |
| --- | --- |
| 🔍 法条检索 | jieba 分词 + BM25，法名直查（如"民法典第1254条说了什么"精确命中）、法名别名加权（民法典/民诉法/消保法…）、口语同义词扩展（高空抛物→抛掷、酒驾→饮酒+机动车）、查询覆盖率与连续短语重排 |
| ✦ 检索式问答 | Top-6 命中条文作为上下文，流式输出回答；提示词严格约束"只引用检索到的条文，不足则明说"，抑制编造 |
| ⚖️ 引用可溯源 | 回答中《法名》第X条为金色角标，点击定位到对应法条卡片；每条命中显示部门法/层级/时效徽章 + 相关度得分条 |
| 📚 法条库浏览 | 按七大部门法浏览 378 部法律的 23,995 条现行条文，支持法律名/条文关键词搜索，历史版本与修正案标注时效 |
| 🌙 体验 | 网页端夜间模式、响应式移动端布局；小程序端流式输出、引用点击定位、底部抽屉核对法条 |
| 🛡 安全 | 访问口令（网页/小程序统一 token，7 天）、每 IP 限流（10 次/分钟）、API Key 仅存服务器 .env |

## 双端

- **网页端**（`web/`）：零构建单页应用，nginx 托管，`/?q=问题` 可直达提问
- **小程序端**（`miniprogram/`）：原生开发，微信开发者工具导入即用；appid 与服务器地址见目录内说明
- **后端 API**（`app/`）：FastAPI，SSE 流式接口 `/api/ask`，法条库 `/api/laws` `/api/search`

## 上线部署

见 **[部署手册.md](部署手册.md)**：轻量服务器购买 → 域名与 ICP 备案 → `deploy/deploy.sh` 一键部署 → certbot HTTPS → 小程序提审。部署资产在 `deploy/`（nginx 配置、systemd 服务、一键脚本）。

## 项目结构

```
├── app/                  # FastAPI 后端
│   ├── main.py           #   路由：/api/ask(SSE) /api/laws /api/search /api/login …
│   ├── retrieval.py      #   BM25 检索 + 法条直查 + 同义词/短语重排
│   ├── llm.py            #   OpenAI 兼容接口流式调用 + 提示词
│   ├── auth.py           #   口令 → HMAC token（7天）
│   ├── ratelimit.py      #   滑动窗口限流
│   └── database.py       #   SQLite 只读层
├── web/                  # 网页前端（零构建）
├── miniprogram/          # 微信小程序
├── scripts/
│   ├── build_corpus.py   # 语料 JSONL → SQLite + BM25 索引
│   ├── test_retrieval.py # 检索自测（10 个典型问题）
│   └── take_screenshots.py
├── deploy/               # nginx / systemd / 一键部署脚本
├── data/                 # laws.db + bm25.pkl（构建产物）
├── PRD.md / 技术设计.md / 部署手册.md
└── screenshots/          # 运行截图
```
